🎣 Discovery Questions for clinic operations directors

Opening Questions
  1. "Tell me about your current approach to [problem area]."
  2. "What's working well? What's not?"
  3. "How is this affecting [relevant business metric]?"
Pain Discovery
  1. "What happens if you don't solve this in the next 6 months?"
  2. "How much time/money does this currently cost you?"
  3. "Who else is affected by this problem?"
Solution Mapping
  1. "What have you tried before? What happened?"
  2. "What would success look like for you?"
  3. "If you could wave a magic wand, what would be different?"
Qualification
  1. "What's your timeline for making a decision?"
  2. "Who else needs to be involved in this evaluation?"
  3. "What's your budget range for solving this?"

Who is Sales Enablement Content not ideal for?

  • Anyone who cannot give the inputs listed above; the answer is built only from them.
  • Teams that want finished, on-brand copy: each tool returns a structured draft to edit, with placeholders where your inputs gave no fact.
  • Anyone who needs research or quotes gathered for them: the tools look nothing up; they work from the story and facts you give, and anything they add themselves is marked as an example, a suggestion or a placeholder.

How do I use Sales Enablement Content from Claude?

Add CRAFT Content once (see Use it in Claude or ChatGPT), then ask in plain words. A prompt built from the tested example:

Use CRAFT Content's Sales Enablement Content tool. product: ExampleCo Scheduler; target persona: Clinic operations directors; proof points: No-shows down 30% at Example Clinic Group, Setup in one day; value props: Fewer no-shows, Setup in one day; sales stage: Discovery.

How does Sales Enablement Content work?

No sign-in. A web browser is enough, and the answer comes back in a second or two.

  1. Fill in the form above, or press Fill in an example.
  2. Press Run Sales Enablement Content.
  3. Read the result on this page, then copy it and edit it before you use it.

It applies fixed rules in the CRAFT Content code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the AI assistant connector run the same tool code, so the same input gives the same answer in both.
