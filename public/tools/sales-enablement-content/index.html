Sales Enablement Content

Generate sales content. Know your objections? Get complete handlers. New product with no sales data yet? We'll suggest likely objections based on your product type.

Run Sales Enablement Content in your browser

Required: Product, Target persona, Proof points. Fields marked optional can be left empty.

Use it from Claude or another assistant

Connect CRAFT Content once (see Connect), then ask in plain words. A prompt built from the tested example:

Use CRAFT Content's Sales Enablement Content tool. product: ClinicFlow, scheduling software for clinics; target persona: Clinic operations directors; proof points: No-shows down 30% at Northwind Clinics, setup in one day; sales stage: discovery.

MCP tool name: sales_enablement_content. REST: POST https://craft-content.gtmhelix.com/api/tools/sales_enablement_content (see Docs).

How this tool works

It applies fixed rules in the CRAFT Content code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server run the same function, so the same input gives the same answer in both.
