Case Study Generator

Generate case studies with DISCOVERY MODE. If you have the full story, get a complete case study. If not, get interview questions to gather the story first.

By Shashwat Ghosh, founder of Helix GTM Consulting · Last updated 25 September 2026

How do I use Case Study Generator from Claude?

Connect CRAFT Content once (see Connect), then ask in plain words. A prompt built from the tested example:

Use CRAFT Content's Case Study Generator tool. customer name: Northwind Clinics; your product: ClinicFlow; customer industry: healthcare; mode: full; challenge: Missed appointments were costing revenue; solution: Automated SMS reminders and online rescheduling; results: No-shows down 30% in 3 months.

MCP tool name: case_study_generator. REST: POST https://craft-content.gtmhelix.com/api/tools/case_study_generator (see Docs).

How does Case Study Generator work?

It applies fixed rules in the CRAFT Content code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server run the same function, so the same input gives the same answer in both.
