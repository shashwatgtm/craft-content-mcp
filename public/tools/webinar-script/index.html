How do I use Webinar Script from Claude?

Connect CRAFT Content once (see Connect), then ask in plain words. A prompt built from the tested example:

Use CRAFT Content's Webinar Script tool. topic: Pipeline forecasting that sales managers trust; target audience: Sales managers at B2B SaaS companies; webinar type: educational; duration: 45 min; product mention level: subtle.

MCP tool name: webinar_script. REST: POST https://craft-content.gtmhelix.com/api/tools/webinar_script (see Docs).

How does Webinar Script work?

It applies fixed rules in the CRAFT Content code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server run the same function, so the same input gives the same answer in both.
