Who is Content Repurposer not ideal for?

  • Anyone who cannot give the required inputs (Source content, Source type); the answer is built only from them.
  • Teams that want finished, on-brand copy: each tool returns a structured draft to edit, with placeholders where your inputs gave no fact.
  • Anyone who needs research or quotes gathered for them: the tools look nothing up and use only the story and facts you give.

How do I use Content Repurposer from Claude?

Connect CRAFT Content once (see Connect), then ask in plain words. A prompt built from the tested example:

Use CRAFT Content's Content Repurposer tool. source content: Most onboarding fails in week one because new customers never reach their first success moment. Map that moment, remove every step before it...; source type: blog post; brand voice: professional.

MCP tool name: content_repurposer. REST: POST https://craft-content.gtmhelix.com/api/tools/content_repurposer with this JSON body (see Docs):

{
  "input": {
    "source_content": "Most onboarding fails in week one because new customers never reach their first success moment. Map that moment, remove every step before it, and measure time to value.",
    "source_type": "blog_post",
    "brand_voice": "professional"
  }
}

How does Content Repurposer work?

It applies fixed rules in the CRAFT Content code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server run the same function, so the same input gives the same answer in both.
