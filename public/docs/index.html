For developers

CRAFT Content docs

The MCP address, the REST API behind the web forms, and every field of all 8 tools.

By Shashwat Ghosh, Co-Founder and Fractional CMO, Helix GTM Consulting · Last updated 29 September 2026

Try these prompts

  1. Use CRAFT Content to draft a customer case study. Customer: Example Clinic Group, healthcare. Our product: ExampleCo Scheduler. Challenge: missed appointments. Solution: automated reminders. Results: no-shows down 30% in 3 months. Mode: full.
  2. Build a practitioner newsletter with CRAFT Content about onboarding checklists for SaaS teams. Call to action: register for our onboarding webinar.
  3. Write a 45-minute educational webinar script with CRAFT Content on pipeline forecasting for sales managers at B2B SaaS companies.
  4. Review this landing page copy with CRAFT Content and suggest improvements: 'Our platform leverages synergies to empower teams to do more with less.'

MCP server

  • Address: https://craft-content.gtmhelix.com/mcp (Streamable HTTP, stateless, JSON responses). GET returns 405 by design.
  • Authentication: none. Every tool is marked read-only (readOnlyHint: true, destructiveHint: false) and has a title.
  • Rate limit: 300 requests per minute per IP address. Server: craft-content-mcp version 2.2.10.
  • Limits: 262,144 bytes per call; text fields up to 4,000 characters, except the document fields interview_notes (Case Study Generator), source_content (Content Repurposer) and content (CRAFT Content Improver), which take up to 100,000; one call per request (no batches). A call over a limit is refused before the tool runs.
  • Local use: npx -y @shashwatgtmalpha/craft-content-mcp runs these tools over stdio (npm can lag behind this site until a new version is published).

REST API (used by the web forms)

Send POST https://craft-content.gtmhelix.com/api/tools/<tool name> with a JSON body {"input": {...}}. The answer is JSON: {"ok": true, "tool": "...", "title": "...", "text": "..."}, where text is the same Markdown the MCP tool returns. The endpoint calls the same server code as the MCP address.

Terminal
curl -s -X POST https://craft-content.gtmhelix.com/api/tools/case_study_generator \
  -H "Content-Type: application/json" \
  -d '{"input": {"customer_name": "Example Clinic Group", "your_product": "ExampleCo Scheduler", "customer_industry": "Healthcare", "mode": "full", "challenge": "Missed appointments costing revenue", "solution": "Automated SMS reminders and online rescheduling", "results": "No-shows down 30% in 3 months"}}'
  • Errors: 400 with errors (missing or invalid fields), 404 for an unknown tool, 405 for methods other than POST, 413 above 32,000 bytes, 422 when the tool itself refuses the input (ok is false and error holds the tool's message), 429 when the rate limit is reached, 500 if the tool fails.
  • Limits: 30 requests per minute per IP address; the whole request up to 32,000 bytes; top-level text fields up to 6,000 characters and top-level lists up to 50 items.
  • Forms without JavaScript post application/x-www-form-urlencoded and get an HTML page back.
  • Nothing is stored and the input is not logged (see Privacy).
