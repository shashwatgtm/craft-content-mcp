Use it from Claude or another assistant

Connect CRAFT Content once (see Connect), then ask in plain words. A prompt built from the tested example:

Use CRAFT Content's Newsletter Builder tool. topic: Onboarding checklists for SaaS teams; cta goal: register for our onboarding webinar; audience segment: practitioners; newsletter type: educational; tone: conversational.

MCP tool name: newsletter_builder. REST: POST https://craft-content.gtmhelix.com/api/tools/newsletter_builder (see Docs).

How this tool works

It applies fixed rules in the CRAFT Content code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server run the same function, so the same input gives the same answer in both.
