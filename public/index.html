Who is CRAFT Content not ideal for?

  • Teams that want finished copy in their brand voice: each tool returns a structured draft to edit, with placeholders wherever your inputs did not supply a fact.
  • Anyone who needs research or quotes gathered for them: the tools do not look anything up. They work from the story and facts you give, and anything they add themselves is marked as an example, a suggestion or a placeholder.
  • Teams that need to save drafts or send them for approval: answers are not stored, so keep each result where you keep the rest of your work.

How do I use CRAFT Content?

  • In your browser: open a tool above and press Fill in an example to see how it works, then run it with your own details.
  • In ChatGPT: install the Helix Content Studio plugin from the ChatGPT plugin directory, then ask in plain words.
  • In supported MCP clients: add CRAFT Content once as a custom connector (there is no sign in), then ask in plain words. For the steps, see Use it in Claude, ChatGPT or Gemini.

Questions people ask

Is there a free MCP connector for B2B content marketing, such as case studies, newsletters and thought leadership?

Yes. CRAFT Content, by Helix GTM Consulting, has nine content tools: case studies, newsletters, webinar scripts, content repurposing, thought leadership series, testimonial requests, sales enablement content, a CRAFT review of any draft and one customer result turned into four checked drafts. It is for demand generation heads and marketing teams, and each tool returns a structured draft to edit.

Is there a free case study generator for B2B companies that works in supported MCP clients?

Yes. The Case Study Generator in CRAFT Content takes the customer, your product, and the challenge, solution and results, and returns a case study with key takeaways, plus short versions for a testimonial page, social media and email.

What free AI tool writes a webinar script and repurposes content into LinkedIn posts?

In CRAFT Content, Webinar Script builds a run of show, a full script with timings, Q&A preparation and a sequence of follow up emails. Content Repurposer turns a piece of content into key points, a LinkedIn post, an X thread, an email, a blog summary, quote cards and a distribution plan.

How do I use CRAFT Content in supported MCP clients, and is it free?

CRAFT Content is free to use, with no account, sign in or API key. In ChatGPT, install the Helix Content Studio plugin from the ChatGPT plugin directory. Or add https://craft-content.gtmhelix.com/mcp as a custom connector in Claude (web, desktop or mobile), in ChatGPT on plans that allow developer mode, or in Cursor, VS Code or Windsurf; in Claude Code, run claude mcp add --transport http craft-content https://craft-content.gtmhelix.com/mcp. You can also run the tools in a browser on this site.

Does it use AI to write the answers?

No. Each tool applies fixed rules in the CRAFT Content code to the inputs you give it. It does not call an AI model and does not look anything up. When you use it from Claude or another assistant, that assistant writes around the tool's answer.

What happens to what I type?

It is sent to this site's server, used once to build the answer, and dropped when the answer is sent back. What you type and the answer are not stored, and nothing you type is logged. Only an anonymous count of tool calls is kept. The privacy page has the details.

How to read the answer

Every tool on this site returns a structured draft with headings, checklists, and bracketed placeholders where you did not supply a fact. Any benchmark, target, rate, or count you did not provide is labelled as an example figure to replace with your own before publishing or sharing.
